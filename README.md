# BrightSide Digital — Project 1

A responsive digital marketing agency website built with HTML5 and CSS3, matching the Brandoptix internship brief for Project 1.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `portfolio.html` — Portfolio
- `contact.html` — Contact
- `style.css` — Shared responsive styles

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Responsive design
The shared stylesheet includes desktop, tablet, and mobile breakpoints. The mobile navigation uses a CSS checkbox toggle, so no JavaScript is needed.

## Contact form note
The contact form uses `mailto:` as a no-backend demonstration. It opens the visitor's email app and does not store submissions. Replace the demo email `hello@brightside.example` with your own email before submission, or connect a form service if your evaluator expects online form submissions.

## Deployment
Upload all six files to a GitHub repository and enable GitHub Pages from **Settings → Pages → Deploy from a branch → main → /(root)**. Use the resulting live URL in your submission.
